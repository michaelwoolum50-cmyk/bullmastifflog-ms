# BullmastiffLog — jurnal untuk pemilik Bullmastiff

Salam, saya michaelwoolum — pembangun aplikasi ini.

Bullmastiff dibiakkan untuk kerja jaga malam: tenang, berani, sangat setia, dan beratnya mudah melebihi 45 kg. Bila doktor haiwan bertanya tentang berat, makanan, atau sejarah lawatan klinik, jawapan ikut ingatan sahaja tidak cukup.

**BullmastiffLog** ialah jurnal khas untuk pemilik Bullmastiff:

- Log penjagaan harian — berat badan, makanan, dan lawatan ke klinik haiwan
- Rekod keturunan — bapa, ibu, kennel, generasi demi generasi dalam satu buku
- Nota latihan — catat setiap sesi, apa yang berkesan dan apa yang tidak, dan lihat coraknya selepas beberapa bulan
- Peribadi — buku Bullmastiff anda kekal dalam peranti anda sendiri
